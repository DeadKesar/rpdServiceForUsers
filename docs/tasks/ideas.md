# Идеи за пределами заданий

*Замечено по ходу работы, в текущее задание не входит. Решение — за автором.*

- **Шум в консоли клиента.** Blazor пишет в консоль браузера info-сообщения «Authorization failed» от каждой проверки ролей в меню; достаточно уровня Warning для клиента (`builder.Logging.SetMinimumLevel`).
- **Сообщить авторам Corvus.JsonSchema об ошибке `format: "regex"`.** Версия 5.7.9 при утверждении форматов считает `"\\."` (экранированную точку) неверным регулярным выражением, хотя для ECMA-262 оно верно, и сама же компилирует такой `pattern` без ошибок. Обойдено: метасхема проверяется без утверждения форматов.
- **Назначение дисциплин преподавателям (перспектива).** Сейчас любой преподаватель может создать РПД по любой дисциплине плана, если документа по ней ещё нет (этап 4, B3). В вузе дисциплины закрепляет кафедра: назначение «дисциплина — преподаватель» ограничило бы создание и список «Мои документы» закреплёнными дисциплинами.
- **Правила каталога без реализации** (на этапе 5 реализованы три, `hours_match_curriculum` — в этапе 5.2, B1.1, предупреждением): `all_indicators_covered` (каждый индикатор матрицы — хотя бы в одной теме), `unique_competence_codes`, `literature_main_count`, правила ФОС. Имена в схемах есть, при проверке пропускаются.
- **Отмеченные мной документы (этап 6).** После отметки документ уходит из очереди «Согласование», и согласующий может открыть его только по прямой ссылке — хотя печать согласованного документа ему доступна. На странице «Согласование» можно показать вторым списком документы, которые пользователь уже согласовал или вернул.
- **Возвращённые с согласования в очереди проверки (этап 6).** В списке «Проверка» документ, возвращённый с согласования, не отличается от отправленного автором: плашка видна только в самом документе. Можно пометить такую строку списка.
- **Колонка «Тип» в очереди «Согласование» (этап 6.1, C2).** В панели браузера шириной около 1000 px значение «РПД» переносится по буквам: длинный текст плана отнимает ширину у соседних колонок. Достаточно запретить перенос (`text-nowrap`) или задать колонке минимальную ширину; стоит проверить и списки «Проверка» и «Мои документы».
- **Потеря связи с сервером на странице документа (этап 6.1, C2).** Если сервер перестал отвечать, пока открыт документ с панелью печати, `PrintPanel.LoadAsync` не перехватывает `HttpRequestException` (только `AccessTokenNotAvailableException`): Blazor показывает полосу «Произошла необработанная ошибка» и пишет `crit` в консоль. Проверено остановкой сервера при открытой странице. Тот же приём стоит заложить в опрос колокольчика (C5): фоновый запрос без ответа не должен ломать страницу.
